# Дорожная карта psp360Phoenix

## Где мы сейчас

Собрано и проверено тестами ядро эмуляции:

| Подсистема | Состояние | Покрытие |
|------------|-----------|----------|
| CPUState (модель Allegrex) | готово | GPR, HI/LO, vpr[128][4], COP0 (Status/Cause/EPC/EBase), исключения |
| Память | готово | RAM 32 МБ, VRAM 2 МБ, Scratchpad 16 КБ, **little-endian**, проверки границ |
| Декодер инструкций | готово | MIPS32 + VFPU (поля 7 бит, размер .s/.p/.t/.q) |
| Интерпретатор | готово (базовый) | ~60 инструкций, слоты задержки, единая семантика Step/StepOne/Run |
| Исключения | частично | Arithmetic Overflow (Ov) для ADD/SUB/ADDI; Sys/Bp/RI/AdEL/AdES не реализованы |
| Прерывания | частично | Маска IM в Status, вектор EBase+0x100+irq*0x20; источники прерываний (таймеры, IRQ) отсутствуют |
| VFPU | частично | 9 операций, lane 0. Опподы 0x18/0x19/0x1B/0x34, 7-битные регистры |
| Загрузчик PBP/ELF | готово | форматы v0x100 и v0x200, PT_LOAD, проверка всех границ |
| Тесты | готово | 129 тестов, все проходят; ASan-прогон чист |

**Не сделано:**

| Подсистема | Состояние |
|------------|-----------|
| GPU (Graphics Engine SceGu) | отсутствует полностью — самый крупный пробел |
| Подсистемы Xenos/XAudio | только хостовые заглушки |
| Ввод (маппинг контроллера) | нет |
| Диспетчер системных вызовов | нет (`SYSCALL` только логируется) |
| MMU / трансляция адресов | нет; нет и алиасов RAM `0x08000000`, `0x18000000` |
| Контроль выравнивания | нет: невыровненные LW/SW не возбуждают AdEL/AdES |
| LL/SC, MUL, MADD/MSUB, CLZ/CLO, EXT/INS | не реализованы |
| VFPU: .p/.t/.q (несколько lane), перенос регистров | не реализованы |
| Потоки и таймеры PSP | нет |
| JIT | нет (интерпретатор — единственный путь исполнения) |
| Сборка в XEX | скрипт готов, тулчейн отсутствует |

## Этап 1 — получить рабочий XEX (блокировано)

Требуется установить devkitXenon. См. `../xbox360/README.md`.
Ничего в коде менять не нужно — ядро уже компилируется под `-mcpu=750`.

Критерий готовности: `build_xex.ps1` собирает `psp360.xex`.

## Этап 2 — минимальная графика

Реализовать подсистемы видео через Xenos и вывод одного кадра.
Критерий: на экране Xbox 360 появляется заливка цветом из теста.

## Этап 3 — GPU (SceGu)

Основной объём работ. Нужен разбор команд GE:
`SceGuDrawArray`, `SceGuStart`, `SceGuFinish`, вершинные шейдеры,
текстурный кэш, трансформация вершин.
Критерий: выводится 2D-сцена из тестового приложения.

## Этап 4 — ввод и звук

Маппинг контроллера Xbox 360 на кнопки PSP, вывод звука через XAudio.
Критерий: работает меню с навигацией.

## Этап 5 — системные вызовы

Реализация по `core/syscall_defs.h`. Запуск приложений потребует
всего, что не реализовано.

## Этап 6 — совместимость

Подключение реальных PBP-образов, отладка на них, расширение покрытия
инструкций по мере обнаружения неизвестных опкодов
(счётчик `Interpreter::unimplementedCount()`).

Перед этим стоит закрыть технический долг, который мешает запускать
реальные бинарники:

1. Алиасы карты памяти (`0x08000000`, `0x18000000`) — реальный код PSP
   к ним обращается.
2. Контроль выравнивания: невыравненные LW/SW должны возбуждать AdEL/AdES.
3. `LL/SC`, `MUL`, `MADD/MSUB`, `CLZ/CLO`, `EXT/INS`, `SEB/SEH`.
4. Диспетчер системных вызовов: сейчас `SYSCALL` только пишет в лог.

## Принципы, принятые в проекте

1. **Каждое изменение подтверждено тестом.** Регрессия ловится сразу.
2. **Никаких `assert()` в путях исполнения** — только логирование
   и счётчики. Эмулятор не должен падать на незнакомом опкоде.
3. **Публичные поля CPUState** — зафиксировано решением после того,
   как приватные поля потеряли векторные регистры VFPU.
4. **Никакого фиктивного «успеха».** Заглушка, возвращающая `true`
   без реальной работы, вреднее явной ошибки.
5. **Раскладки полей — из первоисточников.** Догадки о Allegrex не
   принимаются; всё проверяется по PSP CPU Overview и PPSSPP, выводы
   фиксируются в `ARCHITECTURE_NOTES.md`.
6. **Тесты на настоящих машинных словах.** Ручная подстановка полей
   в `Decoded` скрывала ошибки декодирования — такие тесты запрещены.
